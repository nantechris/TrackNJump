Aide / Tutoriel

Bienvenue sur TrackNJump !

L'application de suivi de l'ordre de passage des cavaliers d'une épreuve.

Étape 1 — Créer un concours

Sur la page d'accueil, appuyez sur le bouton en haut à droite pour créer un nouveau concours.

Renseignez le nom et la date du concours, puis validez.

Vous pouvez aussi modifier ou supprimer un concours en glissant vers la gauche.

Vous pouvez aussi faire une modification directe dans la liste : touchez directement le nom ou la date du concours dans la liste, puis validez en sortant du champ.

Étape 2 — Ajouter des épreuves

Appuyez sur un concours pour ouvrir son détail.

Créez ensuite une ou plusieurs épreuves (ex. : CSI 5*, Amateur…) via le bouton .

Vous pouvez aussi modifier le concours avec le bouton .

Dans la liste des épreuves, un badge compteur affiche aussi le nombre d'engagés pour chaque épreuve (exemple : 5).

Le nom de l'épreuve est aussi modifiable en modification directe dans la liste.

Étape 3 — Gérer les cavaliers

Dans la liste des cavaliers, chaque fiche affiche le numéro de dossard, le nom et le cheval.

  • Glissez vers la droite sur une fiche pour marquer le cavalier comme passé (photo prise).
  • Glissez vers la gauche pour marquer SP (passé sans photo).
  • Glissez vers la gauche aussi pour marquer NP (non partant) ou supprimer le cavalier.

Importer une liste de cavaliers depuis un fichier texte.

Réorganisation automatique

Réorganisation automatique : dès qu'un cavalier est marqué passé, il se place automatiquement à la suite du dernier cavalier déjà passé, même s'il n'était pas juste après dans la liste.

De la même manière, les cavaliers marqués NP sont déplacés automatiquement en fin de liste.

Les informations du cavalier sont aussi en modification directe dans la liste : vous pouvez modifier le dossard, le nom et le cheval directement sur la fiche.

Étape 4 — Réorganiser

Maintenez appuyé et glissez pour réorganiser avec les icônes dédiées :

Pour les cavaliers : icône fer à cheval.

Pour les épreuves et concours : poignée de réorganisation.

La réorganisation des concours et épreuves sert surtout à mieux organiser votre affichage.

Étape 5 — Marquer concours / épreuve comme passé

Glissez vers la droite sur un concours ou une épreuve dans la liste pour le/la marquer comme passé(e) (affichage en vert).

Cette action sert surtout à mieux suivre votre avancement visuel dans l'application.
